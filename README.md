# Bannerlord : plateau hexagonal et matériel de jeu

Matériel d'un jeu de plateau pour 2 joueurs : tuiles hexagonales modulaires (une tuile = une case de déplacement), cartes et jetons, à imprimer et coller sur carton. Plateau de forme libre assemblé à la main, avec un noyau fixe.
